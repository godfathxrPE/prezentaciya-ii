# Презентация «ИИ-сервисы Первого БИТа»

Один исходник, один деплой, персональные ссылки. Копий презентации быть не должно.

## Ссылки для менеджеров

| Кто | Ссылка клиенту |
|---|---|
| Юрий Даценко | `https://<домен>/datsenko` |
| Людмила Гутина | `https://<домен>/gutina` |

Ссылка без ключа (`https://<домен>/`) открывается без ФИО и личных контактов —
на слайде 34 остаётся только «Первый БИТ», сайт и продукты. Так случайно
разосланная ссылка не покажет клиенту чужого менеджера.

Запасная форма ссылки, работает всегда и не зависит от настроек хостинга:
`https://<домен>/?c=gutina`. Если персональная ссылка вдруг отдаёт 404 —
значит не доехал `vercel.json`; эта форма выручит на встрече прямо сейчас.

Локально, для репетиции без интернета: `index.html?c=gutina`.

## Добавить менеджера

Правится **один файл — `people.js`**. Открывается любым редактором, внутри
десяток строк и инструкция в шапке. В `index.html` заходить не нужно.

```js
ivanov: {
  name:  'Иван Иванов',
  role:  'Менеджер проектов<br>Первый БИТ, Санкт-Петербург',
  phone: '+7 900 000 00 00',
  email: 'iiivanov@1cbit.ru',
  tg:    '@ivanov'
},
```

Ключ (`ivanov`) — латиницей, строчными, без пробелов; он же попадёт в ссылку.

Чтобы заработала красивая ссылка `/ivanov`, добавьте в `vercel.json` → `rewrites`:

```json
{ "source": "/ivanov", "destination": "/index.html" },
```

**Проверьте до деплоя:** откройте локальный `index.html`, допишите в адресную
строку `?c=ivanov`, долистайте до слайда 34.

### Если ошиблись

| Что случилось | Что увидит клиент |
|---|---|
| Потеряна запятая или кавычка в `people.js` | Слайд 34 без ФИО, остальной дек работает |
| `people.js` не доехал в деплой | То же самое |
| Забыли rewrite в `vercel.json` | `/ivanov` → 404, но `/?c=ivanov` работает |

Чужие контакты не покажутся ни при каком раскладе — это проверено отдельно.

## Деплой

```bash
vercel --prod
```

Из этой папки. Проект один, поэтому «залить не тому» технически невозможно.

Проверка после деплоя — три ссылки:

```
/               → на слайде 34 «Первый БИТ», без ФИО
/?c=gutina      → Людмила Гутина
/gutina         → Людмила Гутина
```

Первые две зависят только от `index.html`, третья — ещё и от `vercel.json`.
Если третья отдаёт 404, а вторая работает — значит `vercel.json` не уехал
в деплой или в нём опечатка в ключе.

`cleanUrls` в конфиге намеренно нет: он переписывает `.html`-пути и конфликтует
с `rewrites`, которые как раз на `/index.html` и указывают.

## PDF

`Презентация-ИИ-Даценко.pdf`, `Презентация-ИИ-Гутина.pdf` — статические копии
на случай, когда нужен файл, а не ссылка. В PDF видео не проигрывается:
карточки заменяются кадром с плашкой «доступно в веб-версии».

PDF пересобирается не вручную — попросите Claude, он рендерит его из этого
же `index.html` через Playwright, по одному файлу на ключ.

## Что где лежит

```
people.js                  контакты менеджеров — единственное, что правится руками
index.html                 весь дек: разметка, стили, шрифт Onest в base64
video/                     16 роликов H.264, 29 МБ
poster/                    первые кадры для карточек
vercel.json                rewrites для персональных ссылок + заголовки
robots.txt                 Disallow: / — дек не индексируется
```

## Правила, чтобы не сломать

- Не копировать папку под нового человека. Для этого есть `people.js`.
- Видео и постеры — только через перекодирование в H.264. Исходники записи
  идут в VP8, который не играет в Safari и QuickTime.
- Перед деплоем: `git commit`. Откат — `git checkout <хэш> -- index.html`.
