# Презентация «ИИ-сервисы Первого БИТа»

Один исходник, один деплой, персональные ссылки. Копий презентации быть не должно.

## Ссылки для менеджеров

| Кто | Ссылка клиенту |
|---|---|
| Юрий Даценко | `https://<домен>/datsenko` |
| Людмила Гутина | `https://<домен>/gutina` |

Ссылка без ключа (`https://<домен>/`) открывается без ФИО и личных контактов —
на слайде 34 остаётся только «Первый БИТ», сайт и продукты. Так случайно
разосланная ссылка не покажет клиенту чужого менеджера.

Локально, для репетиции без интернета: `index.html?c=gutina`.

## Добавить менеджера

Два места, оба в этой папке:

1. `index.html` → блок `var PEOPLE = {…}` в начале скрипта внизу файла.
   Ключ латиницей, строчными. Поля: `name`, `role`, `phone`, `email`, `tg`.
2. `vercel.json` → массив `rewrites`, добавить
   `{ "source": "/новыйключ", "destination": "/index.html" }`.

Забыли второе — ссылка `/новыйключ` отдаст 404. Забыли первое — откроется
нейтральный вариант без контактов. Ни в том, ни в другом случае чужие
контакты не покажутся.

## Деплой

```bash
vercel --prod
```

Из этой папки. Проект один, поэтому «залить не тому» технически невозможно.

## PDF

`Презентация-ИИ-Даценко.pdf`, `Презентация-ИИ-Гутина.pdf` — статические копии
на случай, когда нужен файл, а не ссылка. В PDF видео не проигрывается:
карточки заменяются кадром с плашкой «доступно в веб-версии».

PDF пересобирается не вручную — попросите Claude, он рендерит его из этого
же `index.html` через Playwright, по одному файлу на ключ.

## Что где лежит

```
index.html                 весь дек: разметка, стили, шрифт Onest в base64
video/                     16 роликов H.264, 29 МБ
poster/                    первые кадры для карточек
vercel.json                rewrites для персональных ссылок + заголовки
robots.txt                 Disallow: / — дек не индексируется
```

## Правила, чтобы не сломать

- Не копировать папку под нового человека. Для этого есть `PEOPLE`.
- Видео и постеры — только через перекодирование в H.264. Исходники записи
  идут в VP8, который не играет в Safari и QuickTime.
- Перед деплоем: `git commit`. Откат — `git checkout <хэш> -- index.html`.
